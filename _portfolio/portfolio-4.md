This document was created as part of a take-home test for a job interview for a cybersecurity company that did not go anywhere. I was asked to analyze an API request in the provided documentation from Whoisxmlapi, learn how to use Postman to create and test this API request successfully by myself, and ultimately, provide detailed-oriented instructions to help users recreate this API request. 

Given that this was the first time I had heard of any of those programs or jargon, I decided to cater my document towards less tech-savvy people than those typically employed by a cybersecurity company.

Were I to submit this again, I would definitely improve the image annotation as, in hindisight, it is not very clear.

The document was created using Microsoft Word. The full piece may be viewed [here](/files/Bring_Home_AidanLee.pdf)
